Título del proyecto

Manual Básico de Uso de GitHub



Descripción

Este proyecto contiene un manual básico sobre el uso de GitHub. Su objetivo es enseñar a los estudiantes cómo utilizar esta plataforma para crear repositorios, guardar cambios, subir archivos y organizar proyectos de programación de manera sencilla.
11. Contenido del manual
El documento PDF incluye los siguientes temas:





¿Qué es GitHub?
GitHub es una plataforma en línea que permite guardar, organizar y compartir proyectos de programación, facilitando el trabajo en equipo




Funciones principales de GitHub.
Permite crear repositorios, guardar cambios, trabajar en equipo, organizar tareas y compartir proyectos.



Repositorios públicos y privados.

Los públicos pueden ser vistos por cualquier persona, mientras que los privados solamente pueden ser vistos por el propietario y las personas autorizadas.


Commits.
Son registros que guardan los cambios realizados en un proyecto y permiten identificar qué modificaciones se hicieron.


Branches (ramas).

Son versiones independientes de un proyecto que permiten realizar cambios sin afectar el proyecto principal.

Issues.
Sirven para reportar errores, organizar tareas pendientes y proponer mejoras en un proyecto.

Creación de una cuenta en GitHub.
Se ingresa a www.github.com, se selecciona Sign up, se escribe un correo electrónico, se crea una contraseña y se verifica la cuenta.


Creación de repositorios.

Se inicia sesión, se presiona el signo +, se selecciona New repository, se escribe el nombre, se elige la privacidad y se presiona Create repository.

Subida de archivos.

Se entra al repositorio, se selecciona Add file, luego Upload files, se eligen los archivos y se presiona Commit changes.

Edición de archivos.

Se abre el archivo, se presiona el icono del lápiz, se realizan los cambios y se selecciona Commit changes para guardarlos.

Glosario básico.
Repositorio: Lugar donde se guardan los archivos de un proyecto.
Commit: Registro de los cambios realizados.
Branch: Rama o versión independiente de un proyecto.
README: Archivo que explica de qué trata un proyecto.
Clonar: Hacer una copia de un repositorio en una computadora.
