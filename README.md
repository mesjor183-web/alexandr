Manual Básico de Uso de GitHub
10. Descripción
Este proyecto contiene un manual básico sobre el uso de GitHub. Su objetivo es enseñar a los estudiantes cómo utilizar esta plataforma para crear repositorios, guardar cambios, subir archivos y organizar proyectos de programación de manera sencilla.
11. Contenido del manual
El documento PDF incluye los siguientes temas:
¿Qué es GitHub?
Funciones principales de GitHub.
Repositorios públicos y privados.
Commits.
Branches (ramas).
Issues.
Creación de una cuenta en GitHub.
Creación de repositorios.
Subida de archivos.
Edición de archivos.
Glosario básico.
